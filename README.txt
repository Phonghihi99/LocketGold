GÓI TẠO MODULE LOCKET - TUANPHONG275

1) Tải hai file này vào repository Phonghihi99/LocketGold đúng đường dẫn:
   .github/workflows/update-locket-banner.yml
   scripts/build_locket.py
2) Trong GitHub, mở tab Actions -> Build Locket TuanPhong275 banner -> Run workflow.
   Workflow sẽ tải bản Locket_Unlocked.js gốc từ duyvinh09, thay đúng 5 giá trị quảng bá,
   kiểm tra cú pháp JavaScript rồi ghi vào js/Locket_Unlocked.js của repository của bạn.
3) Tải thêm TuanPhong275_Locket_Banner.sgmodule vào thư mục gốc repository.
4) Nhập liên kết RAW của module này vào Shadowrocket và thử các tính năng.

Lưu ý: Không có bản JS hoàn chỉnh trong ZIP vì môi trường này không thể tải file thô về.
Workflow chỉ chạy khi bạn chủ động bấm Run workflow, và cần Actions có quyền ghi contents.
Ảnh banner sử dụng đường dẫn bạn từng cung cấp; kiểm tra link ảnh còn hoạt động.
Chưa bảo đảm Locket vẫn chấp nhận các cờ Remote Config hoặc Gold máy chủ.
Nguồn script gốc cần ghi nhận tác giả duyvinh09.
